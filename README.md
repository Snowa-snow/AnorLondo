# 🎓 Школа AnorLondo - Веб-сайт учебного заведения

Добро пожаловать в документацию проекта! Этот файл объясняет, что представляет собой сайт, как он устроен, какие технологии используются и как его можно улучшить в будущем.

---

## 📌 1. О проекте
**AnorLondo School** — это современный веб-сайт для школы, разработанный на фреймворке **Django**. 
Сайт создан для того, чтобы ученики, родители и учителя могли в удобном формате получать актуальную информацию о жизни школы. Проект сочетает в себе классическую информационную структуру и современный адаптивный дизайн.

---

## ⚙️ 2. Функционал сайта
На данный момент реализованы следующие возможности:
- **Главная страница**: Приветственный баннер, миссия школы, блок с важными датами (каникулы, экзамены), интерактивная карта проезда и контакты в подвале.
- **Новости**: Список всех событий школы в виде карточек. При клике открывается отдельная страница с полным текстом статьи.
- **Учителя**: Каталог педагогического состава с фотографиями, предметами и краткой биографией.
- **Расписание**: Интерактивная таблица уроков. Пользователь выбирает класс из выпадающего списка, и таблица автоматически перестраивается.
- **Библиотека**: Каталог книг с умным поиском по названию или автору.
- **Админ-панель**: Удобный интерфейс для управления сайтом. Администратор добавляет новости, учителей, книги и расписание без написания кода.

---

## 🛠 3. Технологический стек
- **Backend (Сервер)**: `Python 3.x` + `Django` (основная логика и маршрутизация).
- **Frontend (Клиент)**: 
  - `HTML5` + `Django Templates`
  - `Tailwind CSS` (подключен через CDN) — отвечает за современный дизайн, сетки и адаптивность под мобильные телефоны.
  - `FontAwesome` — библиотека иконок.
- **База данных**: `SQLite` (встроенная база, идеальна для разработки и небольших проектов).
- **Работа с изображениями**: `Pillow` (библиотека Python для обработки загружаемых фото).

## 📂 4. Навигатор по структуре проекта

### 📁 Корневая папка (`AnorLondo/`)
- `manage.py` — **Главный пульт управления**. Через него запускается сервер и создаются миграции.
- `requirements.txt` — Список всех Python-библиотек, необходимых для работы.
- `db.sqlite3` — Файл самой базы данных (в нем хранятся новости, учителя и т.д.).

### 📁 Настройки ядра (`AnorLondo/AnorLondo/`)
- `settings.py` — **Мозг настроек**. Здесь указаны подключенные приложения, настройки языка, времени, базы данных и путей к медиафайлам (`MEDIA_URL`).
- `urls.py` — **Главный маршрутизатор**. Связывает адреса страниц с логикой.

### 📁 Приложение (`AnorLondo/lapp/`)
Это сердце сайта. Вся логика школы находится здесь:
- `models.py` — **Структура базы данных**. Здесь описаны классы `Teacher`, `News`, `Book`, `Schedule`. Каждое поле (например, `title` или `photo`) — это колонка в базе данных.
- `views.py` — **Контроллеры (Логика)**. Функции, которые берут данные из базы и передают их в HTML-шаблоны. Например, поиск книг.
- `admin.py` — Настройка панели администратора.
- `urls.py` — Маршруты для страниц приложения (главная, новости, библиотека и т.д.).
- **`templates/`** — **Внешний вид (HTML)**. 
  - `base.html` — Каркас (меню + подвал). Все страницы наследуются от него.
  - `home.html`, `news_list.html`, `teacher_list.html` и др.
- **`static/`** — Статические файлы (дизайнерские картинки, фоны, логотипы).

### 📁 Медиафайлы (`AnorLondo/media/`)
- `teachers/` — Сюда автоматически скачиваются фотографии учителей, когда вы загружаете их через админ-панель.
